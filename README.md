# Impressive docs

The user docs of [impressive.works](https://impressive.works/docs/), one folder per plugin:

- [`mail/`](mail/) — Impressive Mail

Every page on the site has an "Edit on GitHub" link that opens its file here.

## Suggesting a change

Edit a page on GitHub and open a pull request. This repo is a copy: the docs are written in the
main Impressive repo and copied here on every change. When a pull request is accepted, the change
is made in the main repo, and the next copy brings it here; the pull request is then closed.

Questions about the plugins: [impressive.works/contact](https://impressive.works/contact/).
